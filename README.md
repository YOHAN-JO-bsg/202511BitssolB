# BISSOL : 모바일 웹 기반 커뮤니티 서비스 개발

> 위치 기반 날씨 정보와 음성 콘텐츠(빗소리)를 결합한 모바일 웹 커뮤니티 서비스를 설계·구현하는 것을 목표로 한 프로젝트

<br>

* **개발 기간:** 2025.11.23 ~ 진행중
* **개발 인원:** 총 5명(기능 단위 Full-Stack 협업 방식, 디자이너 1명 포함)

  
<br>

## 기술 스택 (Tech Stack)

| 구분 | 기술 |
| :-- | :-- |
| **Backend** | Java, Spring Boot, REST API, Swagger |
| **Frontend** | React, HTML5, TypeScript, CSS3 |
| **DB & Infra** | Oracle, Docker, Nginx, AWS |
| **협업툴** | Git, GitHub, Notion |

<br>

<br>

## 담당 영역 : 커뮤니티 게시판 도메인 풀스택 개발

* Spring Boot 기반 게시판 도메인 백엔드 API 설계·구현 (게시글 CRUD, 상태 관리, 페이징 처리)
* 댓글·대댓글 CRUD 기능 구현 (계층형 구조 처리 및 게시글 단위 연동)
* 좋아요·투표 기능 구현 (사용자 액션 기반 수치 반영 및 중복 처리 방지)
* 게시글 목록·상세 조회 API 구현 및 React 프론트엔드 연동
* REST API 기반 프론트–백엔드 통합 흐름 설계 및 검증
